Field Manual

Everything on the exam about keeping a network alive, in three ideas.

Redundancy

A network has redundancy when there's more than one path between two points. If one path goes down, traffic still gets through — just by a different route. Redundancy is what makes a network able to survive damage.

Single Point of Failure (SPOF)

A single point of failure is a link or device that, if it fails, cuts off part of the network with no other way through. Spotting the SPOF means tracing every path a site has back to Command — if there's only one path, that path is a SPOF.

Fault Tolerance

A system is fault-tolerant if it keeps working even when a piece of it fails. The real Internet is designed this way on purpose: routers automatically send packets around outages, using whatever redundant paths exist. No redundancy, no fault tolerance — that's the whole game.

How a shift works

Each wave: first you read the grid — a few questions about the network on screen. Then the storm hits and you defend it live — links and towers fail, you dispatch repair crews to fix downed links before Grid Uptime hits zero. Towers (relays) that get destroyed stay down for the wave — only redundancy saves those sites. Waves get bigger and meaner the longer you survive. There's no game over — just how long your grid holds.
